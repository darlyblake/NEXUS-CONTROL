# Feuille de route initiale

1. Installer les dépendances et créer l'application Tauri + React + TypeScript.
2. Construire la navigation et la liste des appareils.
3. Tester MeshCentral séparément avec un ordinateur Windows/Linux de test.
4. Tester ADB et scrcpy avec un téléphone Android autorisé.
5. Ajouter une API locale et le modèle commun des appareils.
6. Relier l'interface aux états réels des connecteurs.
7. Ajouter le réseau privé distant après les tests locaux.
8. Définir des connecteurs pour Android TV, Home Assistant et Apple selon les possibilités réelles.
