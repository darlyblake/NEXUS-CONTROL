# Sécurité

- Garder les premiers tests sur localhost et le réseau local.
- Ne jamais committer de mots de passe, jetons ou clés privées.
- Chaque appareil doit avoir une identité propre et révocable.
- Séparer les droits pour l'écran, les fichiers, les commandes et l'administration.
- Demander une validation explicite avant les opérations sensibles.
- Conserver un journal des actions : utilisateur, cible, heure et résultat.
- Gérer uniquement les appareils pour lesquels le propriétaire a donné son accord.
- Ne pas exposer ADB ou un terminal directement sur Internet.
- Pour iOS/iPadOS, respecter les capacités et mécanismes officiels de gestion Apple.
