# Intégration MeshCentral

Objectif : réutiliser MeshCentral pour gérer les ordinateurs Windows/Linux, avec NEXUS CONTROL comme interface unifiée.

Commencer par installer et tester MeshCentral séparément sur le réseau local. Valider un ordinateur de test avant de concevoir l'intégration par API ou liens profonds.

Documentation : https://docs.meshcentral.com/

Vérifier les API et mécanismes d'authentification de la version utilisée. Ne pas stocker les identifiants MeshCentral dans le frontend.
